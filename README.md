Practical 1: 
Summary
In this practical, we implemented Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, and Quick Sort and studied their working and execution time. Bubble, Selection, and Insertion Sort generally take O(n²) time, while Merge Sort takes O(n log n) time and Quick Sort takes O(n log n) time on average.

Conclusion :
This practical helped us understand different sorting techniques and their performance. We learned that Merge Sort and Quick Sort are generally faster for large datasets.

Practical 2: 
Summary
In this practical, we implemented Linear Search and Binary Search and analyzed their execution time. Linear Search checks elements one by one and takes O(n) time, while Binary Search repeatedly divides a sorted array into halves and takes O(log n) time.

Conclusion :
We learned that Linear Search is simple and can work with unsorted data, whereas Binary Search is faster but requires the array to be sorted.

Practical 3: 
Summary
In this practical, we implemented Max-Heap Sort by first creating a Max Heap and then repeatedly moving the largest element to the end of the array. Heap Sort takes O(n log n) time in the best, average, and worst cases.

Conclusion :
This practical helped us understand how a Max Heap can be used for efficient sorting. Heap Sort provides consistent performance and requires O(1) extra space.

Practical 4:
Summary
In this practical, we implemented factorial using iterative and recursive methods and compared their execution time. Both methods take O(n) time, but the iterative method uses O(1) space, whereas the recursive method uses O(n) space because of recursive function calls.

Conclusion :
We learned the difference between iteration and recursion. The iterative method is more memory-efficient, while recursion provides a simple way to solve the factorial problem by breaking it into smaller problems.
